# 刘明湖个人网站与作品集 2026

这是一个从头整理的新项目，目标不是复刻旧作品集，而是让访问者先认识刘明湖这个人，再继续进入简历、案例和项目库。

## 项目定位

- 页面气质：个人网站 + 作品集
- 求职信息：保留目标岗位、城市、薪资区间
- 目标城市：深圳 / 广州
- 目标薪资：20K-30K
- 核心内容：产品方法论、复杂业务抽象、多项目推进、软硬件一体交付、交付风险控制

## 当前版本内容

- 首页定位与核心履历数据
- 能力模型
- 4 个精选案例入口
- 可点击项目库与详情弹窗
- 经历主线
- 可复制电话 / 邮箱、微信二维码与两页中文简历下载
